# Copias de seguridad de los datos

## Guardar

Pulsa **Guardar todo** para descargar un JSON con colecciones, discos,
composiciones, estilos, posiciones, ajustes y preferencias. También pueden
exportarse ámbitos concretos desde **Importar y exportar**.

Conserva el archivo fuera del navegador. Los datos locales pueden perderse al
borrar el almacenamiento del sitio o cambiar de dispositivo.

## Cargar

En **Importar y exportar**, selecciona el JSON, revisa su contenido y pulsa
**Cargar copia**. Una copia completa sustituye los datos del sistema; las copias
parciales añaden el ámbito importado. Descarga tus datos actuales antes de
sustituirlos.

Las copias completas creadas previamente siguen siendo legibles. Los campos
adicionales ajenos a los datos actuales no se incorporan al sistema.

## Límites

- **Deshacer** actúa sobre cambios de la sesión; no sustituye un JSON descargado.
- Localhost, GitHub Pages y otros navegadores guardan datos separados.
- GitHub conserva el código y las publicaciones, no tus colecciones personales.
- No existe sincronización automática entre dispositivos.
